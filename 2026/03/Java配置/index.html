Java配置

1.安装下载JDK

JDK(Java Development Kit)Java开发者工具包

1.搜索网址：

（英文网址）Java Downloads | Oracle

（中文网址）Java Downloads | Oracle 中国

下载：JDK8；JDK11；JDK17；JDK21；JDK21都可以这些都是长期版本，稳定用17比较多，25比较新

选择第二个：installer进行安装下载

2.配置JDK环境变量

  • 复制安装成功后jdk的里bin文件的目录路径

  • 在设置里找到环境变量

  • 环境变量里面点击新建

  • 按照刚刚复制的路径这样填进去，然后点确定

  • 在系统变量里面找到Path点开之后，点击新建，把刚刚复制的含有bin的路径复制进去，点确定

  • 一直点确定退出后，用cmd验证一下
  • 打开cmd分别别输入java和java -version进行验证

3.安装IDEA

官网：下载 IntelliJ IDEA

点击下载安装

  • 勾选如图选项即可

4.IDEA的中文版本配置

点击左上角->点setting->Plugins->搜索：Chinese (Simplified) Language Pack / 中文语言包；安装后勾选点OK即可

5.IDEA的使用

  • 点击新建项目，填好之后点击创建

  • 左边是项目结构区，右边是文本编辑区

  • 右键点击src->点击新建->软件包

    这里在命名的时候一般会写成域名的反写，比如：com.baidu.test（这样新建的实际上是多个包）

  • 可以继续右键点击新建好的包->新建->Java类；便可以建好一个java文件

  • 写好代码之后要运行点如下几个位置都可以运行文件

6.IDEA其他功能

这个软件在写代码的时候，可以自动补全单词，或者只写代码串的首字母便可以补全一行

比如在输入psvm就可以补全那一行

7.安装AI工具插件

点开设置->插件->搜索

有两款比较好用的：

1.Qoder CN（这个是通义的）

2.TRAE AI（这个是字节的）

按照提示完成安装即可
